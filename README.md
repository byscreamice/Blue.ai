This is a agent.md geneating website for any users new to coding to use to create an agents.md file to use their ai to help them properly code.

There is the main core user flow:

Main core user flow: The user logs on, they can see a few options, where they can easily describe what they want their ai to do, where then an ai api key analzyes the input, then givs them a personalized agents.md file for what they would want to make their ai do. There is also presets, where users can select from a couple of options, such as A Learning agents.md file where their agent can help them learn the code and understand the main user flow for it.
